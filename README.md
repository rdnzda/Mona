# Mona

A Next.js project that has not been developed yet: the repository currently contains the default starter generated by `create-next-app`.

## Tech stack

- Next.js (App Router), React, TypeScript
- Tailwind CSS
- ESLint

## Getting started

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000) and start editing `app/page.tsx`.
